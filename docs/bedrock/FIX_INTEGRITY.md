## Stable combined contract

`wb/WorkbenchStore.kt:68–86` adds `registerVerifiedSnapshot(name, format, bytes, expectedBytes, expectedSha256): ArtifactRecord`. It bounds/copies/checks actual bytes before registration, delegates to existing atomic/quota/format checks, and verifies the full registered record afterward. There is no filesystem path API or authority expansion. `test/VerifiedSnapshotRegistrationTest.kt:12–76` checks exact retained bytes/reopen/idempotency/caller mutation, forged size/hash, malformed format/name, current corruption, and configured quotas. Fixture JSON stating `exitCode:0` is expressly **not** proof that a process ran.

[Integration contract](/home/ubuntu/bedrock-integrity-contract.md) assigns selection/workspace/task ownership, trusted NOFOLLOW transport, real successful build AND behavioral-test observations, provenance checkpoints, and engine-owned write witnesses to terminal/combined owners. Supported formats remain unchanged; PDF/JAR/APK are not admitted. No manifest/Room provenance migration.
