# NYX User Guide — v0.8.0

This legacy filename is retained to avoid removing existing repository documentation. The complete current instructions are in [USER_GUIDE.md](USER_GUIDE.md).

The v0.8.0 guide covers Manual, Smart, and Full autonomy modes; scoped grants and Emergency Stop; native GGUF import and model management; optional Ollama and OpenAI-compatible endpoints; managed host/guest Ollama discovery, start, stop, restart, readiness, and model reconnection; durable Debian PRoot guest sessions; Debian dependency bootstrap with Deb822 APT recognition; policy-gated model terminal commands; automatic objective continuation; the expandable Live Worker Console; managed workspace reuse and guarded deletion; Arsenal skills; MCP and GitHub gateways; project memory; Termux setup (`allow-external-apps=true` and the `RUN_COMMAND` permission); environment discovery and verified PRoot guests; controlled `fetch_url` research; and evidence-based objective completion.

Physical-device validation of the fixed Debian installation path, the new console rendering, workspace deletion, native Android inference, and the prior autonomy flows is still pending. The v0.8.0 implementation is JVM-tested, not claimed as device-verified.
