# NYX Eclipse AI — v0.8.1

This legacy filename is retained so existing links keep working. The canonical project homepage is [README.md](README.md).

NYX v0.8.1 “Project Clear Signal” makes the Live Worker Console run-scoped and operation-oriented, adds run history, measured operation duration, full-detail and raw-event views, confirmation-gated diagnostic clearing, bounded planning with visible progress and one structured-output repair, an honest `needs_attention` planning stop, and stricter model-directed shell syntax. It builds on the v0.8.0 dependency bootstrap and the earlier Debian-aware Ollama and workspace work.

The complete overview, download links, capability status, and honest limitations are in [README.md](README.md); the implementation record is in [NYX_DEVELOPMENT_REPORT.md](NYX_DEVELOPMENT_REPORT.md), the v0.8.1 notes are in [RELEASE_NOTES_v0.8.1.md](RELEASE_NOTES_v0.8.1.md), and the verified test evidence is in [TEST_RESULTS.md](TEST_RESULTS.md).
