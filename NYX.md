# NYX v0.4.0

This file is retained for compatibility with the repository's earlier overview filename. The current project overview is [README.md](README.md), and the current release downloads are available from the [NYX v0.4.0 GitHub Release](https://github.com/ShamelesAbyss/Nyx/releases/tag/v0.4.0).

NYX v0.4.0 adds Room-backed objectives and task graphs, bounded plan validation, dependency-aware serial execution through existing agent tools, and conservative review-before-retry behavior. It remains an autonomy foundation, not a full autonomous computer. The Termux adapter is not a user-facing agent tool, no process-independent background execution or dynamic replanning is included, and device/instrumentation tests remain pending.

See [BUILD.md](BUILD.md), [USER_GUIDE.md](USER_GUIDE.md), [CHANGELOG.md](CHANGELOG.md), [TEST_RESULTS.md](TEST_RESULTS.md), and [NYX_DEVELOPMENT_REPORT.md](NYX_DEVELOPMENT_REPORT.md) for current details. The project retains its Apache-2.0 license in [LICENSE](LICENSE).
