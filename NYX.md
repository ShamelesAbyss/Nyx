# NYX Eclipse AI — v0.8.0

This legacy filename is retained so existing links keep working. The canonical project homepage is [README.md](README.md).

NYX v0.8.0 “Project Autonomous Bootstrap” makes environment preparation part of objective execution: Debian/PRoot environment reconciliation, trusted dependency bootstrap, Debian 13 Deb822 APT source recognition, real JDK candidate resolution, verified executable checks, automatic objective continuation, policy-gated terminal commands, an expandable Live Worker Console, and a guarded workspace lifecycle. It builds on the v0.7.9 durable guest-runtime ownership and the earlier Debian-aware Ollama work.

The complete overview, download links, capability status, and honest limitations are in [README.md](README.md); the implementation record is in [NYX_DEVELOPMENT_REPORT.md](NYX_DEVELOPMENT_REPORT.md), the v0.8.0 notes are in [RELEASE_NOTES_v0.8.0.md](RELEASE_NOTES_v0.8.0.md), and the verified test evidence is in [TEST_RESULTS.md](TEST_RESULTS.md).

Official downloads: [v0.8.0 release](https://github.com/ShamelesAbyss/Nyx/releases/tag/v0.8.0). The APK is ARM64-only and debug-signed, not production-signed.
