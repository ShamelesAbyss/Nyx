# NYX Eclipse AI — v0.8.5

This legacy filename is retained so existing links keep working. The canonical project homepage is [README.md](README.md), and the current release is [NYX v0.8.5 — Project Sovereign](https://github.com/ShamelesAbyss/Nyx/releases/tag/v0.8.5).

v0.8.5 adds adaptive deliberation budgets, durable working state, task-scoped tool authority, a false-success guard, bounded structured-action repair, repeated/consecutive-failure stops, credential redaction, and a two-hour checkpointed objective watchdog. It preserves the existing autonomy policy, workspace authorization, dependency gate, provider snapshots, checkpoints, recovery, and no-root/no-arbitrary-shell boundaries.

The Sovereign execution loop and task-scoped tools have not yet been validated on a physical device or against a real provider/model. See [release notes](RELEASE_NOTES_v0.8.5.md), [implementation report](V085_IMPLEMENTATION_REPORT.md), [test results](TEST_RESULTS.md), and [changelog](CHANGELOG.md) for scope and verification.
