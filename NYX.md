# NYX Eclipse AI — v0.8.4

This legacy filename is retained so existing links keep working. The canonical project homepage is [README.md](README.md), and the current release is [NYX v0.8.4 — Project Endurance](https://github.com/ShamelesAbyss/Nyx/releases/tag/v0.8.4).

v0.8.4 adds observed device intelligence, Eco/Balanced/Performance/Adaptive modes, adaptive native threading at safe boundaries, opt-in bounded calibration, thermal and battery safety ceilings, exact-prefix KV reuse, and a Performance dashboard. It preserves the existing autonomy policy, workspace authorization, dependency gate, checkpoints, recovery, and no-root/no-arbitrary-shell boundaries.

The release owner reports that the Performance dashboard rendered on a Pixel 10 Pro Fold; this is UI evidence only. Native GGUF inference, calibration, exact-prefix KV reuse, and quantitative battery/performance gains remain device-validation items.
