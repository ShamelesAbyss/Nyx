# NYX Eclipse AI — v0.7.7

This legacy filename is retained so existing links keep working. The canonical project homepage is [README.md](README.md).

NYX v0.7.7 “Project Liberation” adds Debian/PRoot-aware Ollama discovery and lifecycle management, environment-scoped process ownership, automatic local-model reconnection before objectives, and repeatable Full-Autonomy workspace creation under an approved root. It preserves the existing llama.cpp CPU runtime, durable objectives, Termux bridge, Arsenal skills, MCP/GitHub gateways, project memory, source symbol index, Live Worker Console, and evidence-based verification. Physical-device validation of the Debian/Ollama path is still pending.

The complete overview, download links, capability status, and honest limitations are in [README.md](README.md); the implementation record is in [NYX_DEVELOPMENT_REPORT.md](NYX_DEVELOPMENT_REPORT.md) and the verified test evidence is in [TEST_RESULTS.md](TEST_RESULTS.md).

Official downloads: [v0.7.7 release](https://github.com/ShamelesAbyss/Nyx/releases/tag/v0.7.7). The APK is ARM64-only and debug-signed, not production-signed.
